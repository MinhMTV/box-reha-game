DataPacket

data class DataPacket(val preTrigger: Boolean, val samplingRate: SensorSamplingRate, val baroData: List<UShort>, val accData: List<Vector3d<Short>>, val gyroData: List<Vector3d<Short>>, val magnetoData: List<Vector3d<Short>>, val packetSize: Int)

Represents a data packet of the dynamics data pipe protocol.

A data packet may contain number of measurements from the accelerometer, gyroscope, barometer and or magnetometer.

The minimum size of a data packet is HEADER_SIZE bytes.
