SensorDataPacket

data class SensorDataPacket(val relativeTimeCounter: Duration, val bleCounter: Int, val samplingRate: SensorSamplingRate, val baroData: List<Int>, val accData: List<Vector3d<Double>>, val gyroData: List<Vector3d<Double>>, val magnetoData: List<Vector3d<Double>>)

Represents a sensor data packet of the dynamics data pipe protocol.

Each sensor has an own sampling rate defined by samplingRate except for magnetoData which always operates at SensorSamplingRate.MAX_MAGNETO_FREQUENCY hertz.

Important: Do not assume that the time axis is normalized across different sensors.

relativeTimeCounter
Link copied to clipboard
val relativeTimeCounter: Duration

The relative time counter of the packet. The glove's clock tick is 100 ms (see RELATIVE_TIME_COUNTER_TICK_DURATION), i.e. this is the finest level of time resolution. Note that multiple SensorDataPackets may have the same relativeTimeCounter as there are sent within the same 100ms window.
